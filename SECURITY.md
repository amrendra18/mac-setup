# Security

## Report a flaw privately

Use [GitHub private vulnerability reporting](https://github.com/amrendra18/mac-setup/security/advisories/new) for this repository.
Describe the affected command or setting, the steps to reproduce the flaw, and its impact.
Use made-up names and a minimal example.

Leave out passwords, API keys, vault password files, encrypted vault files, and real profiles.
Remove personal details from logs. Do not open a public issue containing a security flaw.

## Supported version

The latest `main` branch is supported. Reports should identify the affected commit and macOS version.
